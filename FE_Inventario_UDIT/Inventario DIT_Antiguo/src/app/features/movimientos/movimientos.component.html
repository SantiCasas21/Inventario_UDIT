¿Cómo funciona el ajuste de inventario?

El Ajuste permite corregir el conteo físico de un insumo sin registrarlo como compra o consumo estándar, o bien reubicarlo de estantería.

  • Cantidad positiva (ej: +50) → AUMENTA el stock disponible
  • Cantidad negativa (ej: -30) → REDUCE el stock disponible

La observación es obligatoria para certificar la causa o justificación del ajuste.
