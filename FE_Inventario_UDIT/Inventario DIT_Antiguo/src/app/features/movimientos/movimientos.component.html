¿Cómo funciona el ajuste?

El Ajuste permite corregir el stock de un insumo sin registrarlo como ingreso o salida.

  • Cantidad positiva (ej: +50) → AUMENTA el stock
  • Cantidad negativa (ej: -30) → REDUCE el stock

La observación es obligatoria para registrar el motivo del ajuste.
